# DGA Domain Detection

## 1. Task

Detect malware **Domain Generation Algorithm (DGA)** domains from the domain name
alone. One binary instance, `main`: given a domain **string**, predict DGA
(`1`, algorithmically generated by malware to reach its command-and-control) vs.
legit (`0`, a real/benign domain). Score is the F1-score on the DGA class.

This task has a **deliberately raw feature space**: the only input is the domain
string. There are no pre-computed columns — you must engineer features from the
string yourself (this is the point; it exercises feature engineering, a different
lever from the other cyber-ML tasks whose features are given). The dataset is
balanced (~50% DGA). A weak baseline using a handful of lexical features is
provided; rich character-level features leave real headroom.

## 2. Data

Read inputs from the `DATA_DIR` environment variable:

- `DATA_DIR/main/train.csv` — two columns: `domain` (string, e.g.
  `mortiscontrastatim.com`) and a binary `label` column (`1` = DGA, `0` = legit).
- `DATA_DIR/main/x_test.csv` — one column: `domain` (no label).

Domains include the TLD (`.com`, `.net`, …). Benign domains come from real
popular sites; DGA domains come from 25+ malware families and tend to look random
(high character entropy, unusual n-grams, long consonant runs, digits). See
`data_description.md` for feature ideas.

## 3. Output format (strict)

Write exactly:

    OUTPUT_DIR/main/predictions.csv

with a single integer column **`label_pred`** (`0` or `1`), **one row per row of
`x_test.csv`, in the same order**. `OUTPUT_DIR` is an environment variable.

## 4. Metric

Primary metric: **`Detection F1-Score`** = binary F1 with `pos_label=1` (DGA),
higher is better. Improvement is measured against the weak baseline in
`metadata.json`.

## 5. Notes on compute

Runs on CPU in about a minute. The work is in **featurizing the string**: length,
Shannon entropy, digit / vowel / consonant ratios, longest consonant run,
character and n-gram (bigram/trigram) frequency profiles, ratio of n-grams seen
in English text, `.tld` handling, etc. Classical models (gradient-boosted trees,
logistic regression on n-gram counts, a `CountVectorizer`/`TfidfVectorizer` with
`analyzer="char"`) are strong and fast. A char-level neural model (CNN/LSTM) is
optional and may use Apple **MPS** (`torch.backends.mps.is_available()`) or CUDA,
but is rarely necessary here. Do not fetch external word lists or models — derive
everything from the provided strings and the standard library.

## 6. Entry point (`run.py`)

A complete, runnable baseline follows. It builds seven simple lexical features and
fits a logistic regression — intentionally weak, so there is headroom. Improve via
n-gram / character features, stronger models, and calibration; keep the Section 3
output contract exact.

```python
import math
import os
from collections import Counter

import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

DATA_DIR = os.environ["DATA_DIR"]
OUTPUT_DIR = os.environ["OUTPUT_DIR"]
VOWELS = set("aeiou")


def entropy(s):
    if not s:
        return 0.0
    n = len(s)
    return -sum((c / n) * math.log2(c / n) for c in Counter(s).values())


def featurize(domains):
    d = domains.astype(str).str.lower()
    return pd.DataFrame({
        "length": d.str.len(),
        "num_digits": d.str.count(r"\d"),
        "digit_ratio": d.str.count(r"\d") / d.str.len().clip(lower=1),
        "num_dots": d.str.count(r"\."),
        "entropy": d.map(entropy),
        "vowel_ratio": d.map(lambda s: sum(c in VOWELS for c in s) / max(len(s), 1)),
        "distinct_ratio": d.map(lambda s: len(set(s)) / max(len(s), 1)),
    })


def main():
    train = pd.read_csv(os.path.join(DATA_DIR, "main", "train.csv"))
    x_test = pd.read_csv(os.path.join(DATA_DIR, "main", "x_test.csv"))

    model = Pipeline([("sc", StandardScaler()),
                      ("clf", LogisticRegression(max_iter=200))])
    model.fit(featurize(train["domain"]), train["label"])
    preds = model.predict(featurize(x_test["domain"])).astype(int)

    out_dir = os.path.join(OUTPUT_DIR, "main")
    os.makedirs(out_dir, exist_ok=True)
    pd.DataFrame({"label_pred": preds}).to_csv(
        os.path.join(out_dir, "predictions.csv"), index=False)
    print(f"[main] wrote {len(preds)} predictions")


if __name__ == "__main__":
    main()
```
